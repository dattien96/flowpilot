# 1. What is team?

Team is a group of users who work together on a project.

# 2. Why we need team?

We need team to support the flow with break task and assign task to team member.

# 3. Team vs Project
n-1 relationship.

That mean 1 project can have many teams.
And 1 team can have many projects.

# 4. How to create team?

When user create new project, he/ she need to select a team for that project.
Or create new team and select it for that project.

# 5. How to assign team member?

When user create new team, he/ she need to add team member to that team.

# 6. Team member

Team member is a user who is a member of a team.

# 7. Member data
- Name
- Role: android, ios, backend, frontend, qa, etc
- Level: junior, mid, senior
- Skills: array of string
