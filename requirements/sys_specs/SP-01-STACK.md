# Stack Decision

## Frontend

Recommended:
- React
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query
- React Hook Form
- Zod
- Zustand or Context for lightweight UI state
- React Router

### Why:
- fast MVP development,
- good type safety,
- easy form validation,
- reusable UI components,
- good admin dashboard ecosystem.
