# FlowPilot

FlowPilot is an AI-assisted engineering workflow platform.

Current short-term focus:

- Build the Admin MVP Skeleton first.
- Use Next.js + Supabase for the first version.
- Prove workflow state, approval gates, output history, and context visibility before building real AI orchestration.

## Current confirmed stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase Auth
- Supabase Postgres
- Supabase Realtime
- Supabase Storage
- Supabase Edge Functions if needed
