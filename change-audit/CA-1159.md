# CA-1159 — BUG-630 stale tdd-signatures provenance (task-scoped sections + runner attestation); BUG-629 auto-index disabled under go test

## Context

Live run-174243 cascade root cause (BUG-630): an abandoned run-150388
leg left a Task-033 block in `tdd-signatures.md`; the new run's freeze
treated it as evidence and the file-existence check counted it as this
run's TDD output. Two related weaknesses shared the same file: the
`vibeScaffoldRedWaived` whole-file last-wins scan let one task's
zero-red waiver leak into another task's evaluation, and nothing tied a
ledger block to the run/contract that produced it.

While verifying, the suite's dominant flake surfaced in-process:
`ensureGitNexusIndexAsync` armed `gitnexus analyze` on every unindexed
git workspace — including test fixture tempdirs — and its `.gitnexus/`
writes raced `t.TempDir()` cleanup (BUG-629 cluster 1).

## Changes

1. `internal/runner/vibe_sprint.go` — ledger section parsing
   (`vibeTddSignatureSections`, `(Task-NNN)` header tags, fence-safe
   `# ` split), task-scoped checks (`hasVibeTddSignaturesForTask`,
   `hasVibeTddOutputForTask`, `vibeScaffoldRedWaivedForTask`), the
   provenance gate (`vibeTddFileEvidencePresent`: file evidence requires
   `rs.vibeTddSigAttestedTask == taskID`), and
   `vibeCurrentTaskDocIDLocked` (same task resolution the freeze path
   uses). `vibeTddEvidencePresent` rewired to the attested check;
   contract-lock evidence unchanged.
2. `internal/runner/gate_hook.go` — scaffold-turn block: waiver now
   reads the current task's section; attestation stamps
   `parent.vibeTddSigAttestedTask` only when the leg actually wrote
   `tdd-signatures.md` that turn, then persists the parent session.
3. `internal/runner/flow_executor.go` — coder spawn gate uses the same
   attested file evidence (contract lock path intact).
4. Durable field `vibeTddSigAttestedTask` wired end-to-end:
   `interactiveRun`, `sessionStateOf`,
   `ProviderSessionState` (`workflow_store.go`), `ndjsonSessionRecord`
   both directions, `interactive_resume.go` restore.
5. `internal/runner/gitnexus_autoindex.go` — auto-index early-returns
   under `go test` via the shared `runningUnderGoTest` helper.
6. `internal/agentpack/flow-pack/prompts/scaffold-contract-tdd.md` —
   scaffold leg instructed to treat stale sections as history and write
   its own `(Task-NNN)` section.
7. Tests: `bug630_stale_tdd_signatures_test.go` (6 cases — parsing,
   section-scoped waiver, stale-block-not-evidence, attestation match/
   mismatch, legacy fallback), `bug629_autoindex_test_test.go`
   (auto-index never arms under go test — the test itself spawned the
   indexer on its own tempdir pre-fix, proving the race).
8. `requirements/09-BugFix/todo/BUG-630-*.md`, `BUG-629-*.md` — status
   updated.
