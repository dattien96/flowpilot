# CA-1164 — Task-458 response-language directive: Vietnamese AI chat output

## Context

User request: all AI-authored chat output should be in Vietnamese
("dùng tiếng Việt cho mọi chat với AI"). The captured design
(`Task-458-Response-Language-Directive-Vietnamese.md`) rejected translating
~20 pack prompt files — prompts carry machine contracts (tool names, verdict
enums, `Task-NNN`, JSON schemas) that must stay byte-exact, and prompt
translation per provider/file is unmaintainable. Directive injection is the
chosen approach.

## Change

New file `internal/runner/chat_language.go`:

- `LoadChatLanguage(dotFP)` — reads `.flowpilot/settings/chat-language.json`,
  returns the `language` tag, `""` on missing/corrupt (fail-open, UX not gate).
- `resolvedChatLanguage(workspaceCwd)` — resolution chain: project settings
  file → `FLOWPILOT_CHAT_LANGUAGE` env default → `en`.
- `responseLanguageClause(lang)` — renders the directive; `""` for English,
  a keep-list clause for Vietnamese (and a generic clause for other tags).
  The clause tells the model to answer in the target language for
  natural-language output while keeping tool calls, verdict/status values,
  code, file paths, document ids, and structured payloads exact.
- `promptWithChatLanguage(workspaceCwd, prompt)` — appends the clause;
  byte-identical pass-through under English.

Injection: `interactive_service.go` `startTurn`, immediately after the
`systemPromptTag` stamp at the provider wire boundary. One seam covers every
prompt shape — user turns, `composeAgentSpawnPrompt` output, gate reprompts,
debate/reinvoke notes — which is a simpler realization of the doc's T-3/T-4
composer+envelope pair: the boundary sits downstream of every composer, so
nothing can reach a provider without the clause.

## Verification

- `go test -count=1 -run TestChatLanguage ./internal/runner/` — 6/6 green:
  English default unchanged; vi clause appended after original prompt;
  contract literals (`submit_review_outcome`,
  `approved|changes_requested|blocked`, `AC-1`) byte-exact; corrupt file →
  English; `FLOWPILOT_CHAT_LANGUAGE` env fallback; project file beats env.
- `go vet ./internal/runner/` + `go build ./...` clean.

## Out of scope (per Task-458)

Gate messages, option cards, step labels (Go-composed runner telemetry),
CA docs/commit messages. English default is byte-identical — no prompt
changes for existing projects.
